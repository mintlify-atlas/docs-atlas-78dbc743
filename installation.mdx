## Installation Methods

### Method 1: Quick Installation (Recommended)

<Steps>
  <Step title="Install PHP and Composer">
    Use the official PHP installer for your operating system:

    <CodeGroup>
    ```bash Mac
    /bin/bash -c "$(curl -fsSL https://php.new/install/mac/8.4)"
    ```

    ```powershell Windows (Run as Administrator)
    Set-ExecutionPolicy Bypass -Scope Process -Force; [System.Net.ServicePointManager]::SecurityProtocol = [System.Net.ServicePointManager]::SecurityProtocol -bor 3072; iex ((New-Object System.Net.WebClient).DownloadString('https://php.new/install/windows/8.4'))
    ```

    ```bash Linux
    /bin/bash -c "$(curl -fsSL https://php.new/install/linux/8.4)"
    ```
    </CodeGroup>

    <Warning>
    **Important**: Restart your terminal after installation to ensure PHP and Composer are added to your PATH.
    </Warning>

    Verify the installation:
    ```bash
    php --version
    composer --version
    ```
  </Step>

  <Step title="Clone and setup project">
    Clone the repository and install dependencies:

    ```bash
    git clone https://github.com/MOSHE9647/ServITech-Backend.git
    cd ServITech-Backend
    composer install
    npm install
    ```
  </Step>

  <Step title="Configure environment">
    Create and configure your `.env` file:

    ```bash
    cp .env.example .env
    ```

    Generate required keys:
    ```bash
    php artisan key:generate
    php artisan jwt:secret
    ```
  </Step>

  <Step title="Setup database">
    Run migrations to create database tables:

    ```bash
    php artisan migrate
    ```
  </Step>

  <Step title="Start development server">
    Launch all services:

    ```bash
    composer run dev
    ```
  </Step>
</Steps>

### Method 2: Manual Installation

For more control over the installation process:

<Steps>
  <Step title="Install PHP manually">
    Download and install PHP 8.2+ from [php.net](https://www.php.net/downloads.php)
    
    Ensure these extensions are enabled:
    - `php-mbstring`
    - `php-xml`
    - `php-pdo`

    - `php-zip`
    - `php-tokenizer`
  </Step>

  <Step title="Install Composer">

  </Step>


  <Step title="Clone and configure">


## Environment Configuration

### Basic Configuration

Your `.env` file contains essential configuration. Here are the key sections:

#### Application Settings

```dotenv
APP_NAME=ServITech
APP_VERSION=1.0.0
APP_ENV=local
APP_KEY=         # Generated by php artisan key:generate
APP_DEBUG=true
APP_URL=http://localhost:8000

APP_LOCALE=es
APP_FALLBACK_LOCALE=en
APP_FAKER_LOCALE=es_ES
```

<Note>
- `APP_ENV`: Set to `local` for development, `production` for production
- `APP_DEBUG`: Set to `false` in production to hide error details
- `APP_LOCALE`: Default language (es=Spanish, en=English)
</Note>

#### Database Configuration

<CodeGroup>
```dotenv SQLite (Default)
DB_CONNECTION=sqlite
# No additional configuration needed
```

```dotenv MySQL
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=servitechdb
DB_USERNAME=root
DB_PASSWORD=your_password
```
</CodeGroup>

<Warning>
**Security**: Never commit your `.env` file to version control. It contains sensitive credentials.
</Warning>

#### API Documentation

```dotenv
# Scramble API Documentation Route
SCRAMBLE_API_ROUTE=/docs/api
```

The API documentation will be available at `http://localhost:8000/docs/api`

### Advanced Configuration

#### Session and Cache

```dotenv
SESSION_DRIVER=database
SESSION_LIFETIME=120

CACHE_STORE=database
```

#### Queue Configuration

```dotenv
QUEUE_CONNECTION=database
```

<Note>
The `composer run dev` command automatically starts a queue worker for background jobs.
</Note>

#### Mail Configuration

```dotenv
MAIL_MAILER=log          # Use 'smtp' for production
MAIL_HOST=127.0.0.1
MAIL_PORT=2525
MAIL_USERNAME=null
MAIL_PASSWORD=null
MAIL_FROM_ADDRESS="hello@example.com"
MAIL_FROM_NAME="${APP_NAME}"
```

## Database Setup

### Using SQLite (Development)

SQLite requires no additional setup:


The SQLite database file will be created at `database/database.sqlite`.

  </Step>
</Steps>

## Running the Application

### Development Mode

The recommended way to run the application in development:

```bash
composer run dev
```

This starts three concurrent processes:
- **PHP server** on port 8000
- **Queue worker** for background jobs
- **Vite dev server** for frontend assets

<Note>
You can customize the number of PHP workers by setting `PHP_CLI_SERVER_WORKERS` in your `.env` file (default: 4).
</Note>

### Individual Services

You can also run services individually:

<CodeGroup>
```bash Server Only
php artisan serve
```

```bash Queue Worker Only
php artisan queue:listen --tries=1
```

```bash Asset Compilation Only
npm run dev
```
</CodeGroup>

### Production Mode

For production deployment:

```bash
# Build frontend assets
npm run build

# Optimize Laravel
php artisan config:cache
php artisan route:cache
php artisan view:cache

# Start queue worker as daemon
php artisan queue:work --daemon
```

<Warning>
**Production Checklist**:
- Set `APP_ENV=production`
- Set `APP_DEBUG=false`
- Use a proper web server (Nginx/Apache)
- Configure SSL/TLS certificates
- Set up proper queue workers with supervisord
- Enable opcode caching (OPcache)
</Warning>

## Troubleshooting

### Common Issues

<AccordionGroup>
  <Accordion title="Port 8000 already in use">
    Change the port when starting the server:
    ```bash
    php artisan serve --port=8080
    ```
    
    Update `APP_URL` in your `.env`:
    ```dotenv
    APP_URL=http://localhost:8080
    ```
  </Accordion>

  <Accordion title="Permission denied on storage directories">
    Fix file permissions:
    ```bash
    chmod -R 775 storage
    chmod -R 775 bootstrap/cache
    ```
    
    On Linux/Mac, you may need to change ownership:
    ```bash
    sudo chown -R $USER:www-data storage bootstrap/cache
    ```
  </Accordion>

  <Accordion title="Database connection failed">
    **For SQLite**:
    ```bash
    # Ensure the database directory exists
    mkdir -p database
    touch database/database.sqlite
    php artisan migrate
    ```
    
    **For MySQL**:
    ```bash
    # Test MySQL connection
    mysql -u root -p -e "SHOW DATABASES;"
    
    # Verify credentials in .env match your MySQL setup
    # Try connecting with the credentials manually first
    ```
  </Accordion>

  <Accordion title="Composer install fails">
    Clear Composer cache and try again:
    ```bash
    composer clear-cache
    composer install --no-cache
    ```
    
    If you encounter memory limit errors:
    ```bash
    php -d memory_limit=-1 /path/to/composer install
    ```
  </Accordion>

  <Accordion title="JWT secret not set">
    Generate the JWT secret:
    ```bash
    php artisan jwt:secret
    ```
    
    This adds the secret to your `.env` file. If the command doesn't exist:
    ```bash
    composer require tymon/jwt-auth
    php artisan vendor:publish --provider="Tymon\JWTAuth\Providers\LaravelServiceProvider"
    php artisan jwt:secret
    ```
  </Accordion>

  <Accordion title="NPM install errors">
    Try clearing the NPM cache:
    ```bash
    npm cache clean --force
    rm -rf node_modules package-lock.json
    npm install
    ```
  </Accordion>
</AccordionGroup>
