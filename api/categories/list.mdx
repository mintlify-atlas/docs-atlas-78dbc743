<Warning>
  **ADMIN ACCESS REQUIRED** - This endpoint requires authentication with an ADMIN role.
</Warning>

## Overview

Retrieves a list of all categories in the system, ordered by ID in descending order (newest first).

## Authentication

This endpoint requires:
- Valid JWT token in the `Authorization` header
- User must have **ADMIN** role

## Request

No parameters required.

## Response

<ResponseField name="success" type="boolean" required>
  Indicates if the request was successful
</ResponseField>

<ResponseField name="message" type="string" required>
  Success message indicating categories were retrieved
</ResponseField>

<ResponseField name="data" type="object" required>
  <ResponseField name="categories" type="array" required>
    Array of category objects
    <ResponseField name="id" type="integer" required>
      Unique identifier for the category
    </ResponseField>
    <ResponseField name="name" type="string" required>
      Category name (max 255 characters)
    </ResponseField>
    <ResponseField name="description" type="string">
      Optional category description (max 255 characters)
    </ResponseField>
    <ResponseField name="created_at" type="string" required>
      Timestamp when the category was created
    </ResponseField>
    <ResponseField name="updated_at" type="string" required>
      Timestamp when the category was last updated
    </ResponseField>
    <ResponseField name="deleted_at" type="string">
      Timestamp when the category was soft deleted (null if active)
    </ResponseField>
  </ResponseField>
</ResponseField>

## Code Examples

<CodeGroup>

```bash cURL
curl -X GET "https://api.example.com/category" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -H "Accept: application/json" \
  -H "Accept-Language: en"
```

```javascript JavaScript
const response = await fetch('https://api.example.com/category', {
  method: 'GET',
  headers: {
    'Authorization': 'Bearer YOUR_JWT_TOKEN',
    'Accept': 'application/json',
    'Accept-Language': 'en'
  }
});

const data = await response.json();
console.log(data.data.categories);
```

```python Python
import requests

headers = {
    'Authorization': 'Bearer YOUR_JWT_TOKEN',
    'Accept': 'application/json',
    'Accept-Language': 'en'
}

response = requests.get(
    'https://api.example.com/category',
    headers=headers
)

data = response.json()
print(data['data']['categories'])
```

</CodeGroup>

## Error Codes

| Status Code | Description |
|-------------|-------------|
| 200 | Success - Categories retrieved |
| 401 | Unauthorized - Invalid or missing JWT token |
| 403 | Forbidden - User does not have ADMIN role |
| 500 | Internal Server Error |
