## Endpoints

This page documents two GET endpoints for retrieving articles:

### Get Articles by Category
```
GET /articles/{category}
```

### Get Article by ID
```
GET /articles/id/{id}
```

<Note>
  Both endpoints do NOT require authentication. They are publicly accessible.
</Note>

---

## Get Articles by Category

Retrieves all articles belonging to a specific category.

### Path Parameters

<ParamField path="category" type="string" required>
  The name of the category to filter articles by (e.g., "Tech", "Anime")
</ParamField>

### Headers

<ParamField header="Accept-Language" type="string" default="en">
  Language preference for response messages. Supported values: `en`, `es`
</ParamField>

<ParamField header="Accept" type="string" default="application/json">
  Response content type
</ParamField>

### Response

<ResponseField name="success" type="boolean" required>
  Indicates whether the request was successful
</ResponseField>

<ResponseField name="message" type="string" required>
  Human-readable message describing the result
</ResponseField>

<ResponseField name="data" type="object" required>
  <Expandable title="properties">
    <ResponseField name="articles" type="array" required>
      Array of article objects matching the category
      
      <Expandable title="article object">
        <ResponseField name="id" type="integer" required>
          Unique identifier for the article
        </ResponseField>
        
        <ResponseField name="category_id" type="integer" required>
          ID of the category this article belongs to
        </ResponseField>
        
        <ResponseField name="subcategory_id" type="integer" required>
          ID of the subcategory this article belongs to
        </ResponseField>
        
        <ResponseField name="name" type="string" required>
          Name of the article
        </ResponseField>
        
        <ResponseField name="description" type="string" required>
          Detailed description of the article
        </ResponseField>
        
        <ResponseField name="price" type="number" required>
          Price of the article (minimum 0)
        </ResponseField>
        
        <ResponseField name="images" type="array">
          Array of associated images
        </ResponseField>
        
        <ResponseField name="category" type="object">
          Category details
        </ResponseField>
        
        <ResponseField name="subcategory" type="object">
          Subcategory details
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

### Example Request

<CodeGroup>

```bash curl
curl -X GET https://api.example.com/articles/Tech \
  -H "Accept: application/json" \
  -H "Accept-Language: en"
```

```javascript JavaScript
const category = 'Tech';
const response = await fetch(`https://api.example.com/articles/${category}`, {
  method: 'GET',
  headers: {
    'Accept': 'application/json',
    'Accept-Language': 'en'
  }
});

const data = await response.json();
console.log(data.data.articles);
```

```python Python
import requests

category = 'Tech'
response = requests.get(
    f'https://api.example.com/articles/{category}',
    headers={
        'Accept': 'application/json',
        'Accept-Language': 'en'
    }
)

data = response.json()
print(data['data']['articles'])
```

</CodeGroup>

## Get Article by ID

Retrieves a specific article by its unique ID.

### Path Parameters

<ParamField path="id" type="integer" required>
  The unique ID of the article to retrieve
</ParamField>

### Headers

<ParamField header="Accept-Language" type="string" default="en">
  Language preference for response messages. Supported values: `en`, `es`
</ParamField>

<ParamField header="Accept" type="string" default="application/json">
  Response content type
</ParamField>

### Response

<ResponseField name="success" type="boolean" required>
  Indicates whether the request was successful
</ResponseField>

<ResponseField name="message" type="string" required>
  Human-readable message describing the result
</ResponseField>

<ResponseField name="data" type="object" required>
  <Expandable title="properties">
    <ResponseField name="article" type="object" required>
      The requested article object
      
      <Expandable title="properties">
        <ResponseField name="id" type="integer" required>
          Unique identifier for the article
        </ResponseField>
        
        <ResponseField name="category_id" type="integer" required>
          ID of the category this article belongs to
        </ResponseField>
        
        <ResponseField name="subcategory_id" type="integer" required>
          ID of the subcategory this article belongs to
        </ResponseField>
        
        <ResponseField name="name" type="string" required>
          Name of the article
        </ResponseField>
        
        <ResponseField name="description" type="string" required>
          Detailed description of the article
        </ResponseField>
        
        <ResponseField name="price" type="number" required>
          Price of the article (minimum 0)
        </ResponseField>
        
        <ResponseField name="images" type="array">
          Array of associated images
        </ResponseField>
        
        <ResponseField name="category" type="object">
          Category details with id and name
        </ResponseField>
        
        <ResponseField name="subcategory" type="object">
          Subcategory details with id and name
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

### Example Request

<CodeGroup>

```bash curl
curl -X GET https://api.example.com/articles/id/1 \
  -H "Accept: application/json" \
  -H "Accept-Language: en"
```

```javascript JavaScript
const articleId = 1;
const response = await fetch(`https://api.example.com/articles/id/${articleId}`, {
  method: 'GET',
  headers: {
    'Accept': 'application/json',
    'Accept-Language': 'en'
  }

const data = await response.json();
```

```python Python

        'Accept': 'application/json',
        'Accept-Language': 'en'
```

## Implementation Notes

- The category endpoint uses a `whereHas` query to filter articles by category name
- Both endpoints eager-load relationships (images, category, subcategory) for optimal performance
- Laravel's route model binding is used for the ID endpoint for automatic 404 handling
- If no articles match the category, a 404 error is returned
