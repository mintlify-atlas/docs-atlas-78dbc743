---
title: 'Update Subcategory'
api: 'PUT /subcategories/{id}'
description: 'Update an existing subcategory'
---

This endpoint updates an existing subcategory with the provided information. All fields are optional and only provided fields will be updated.

## Authentication

This endpoint does not require authentication.

## Path Parameters

<ParamField path="id" type="integer" required>
  The unique identifier of the subcategory to update
</ParamField>

## Request Body

<ParamField body="name" type="string">
  Name of the subcategory
  
  **Validation:**
  - Optional (only validated if provided)
  - Must be a string
  - Maximum length: 255 characters
</ParamField>

<ParamField body="description" type="string">
  Description of the subcategory
  
  **Validation:**
  - Optional (nullable)
  - Must be a string
  - Maximum length: 1000 characters
</ParamField>

<ParamField body="category_id" type="integer">
  ID of the parent category
  
  **Validation:**
  - Optional (only validated if provided)
  - Must be a valid category ID that exists in the categories table
</ParamField>

## Response

<ResponseField name="success" type="boolean">
  Indicates if the request was successful
</ResponseField>

<ResponseField name="message" type="string">
  A success message confirming the update
</ResponseField>

<ResponseField name="data" type="object">
  <Expandable title="data">
    <ResponseField name="subcategory" type="object">
      <Expandable title="subcategory">
        <ResponseField name="id" type="integer">
          Unique identifier for the subcategory
        </ResponseField>
        
        <ResponseField name="name" type="string">
          Updated name of the subcategory
        </ResponseField>
        
        <ResponseField name="description" type="string">
          Updated description of the subcategory (nullable)
        </ResponseField>
        
        <ResponseField name="category" type="object">
          The parent category information
          <Expandable title="category">
            <ResponseField name="id" type="integer">
              Unique identifier for the category
            </ResponseField>
            
            <ResponseField name="name" type="string">
              Name of the category
            </ResponseField>
            
            <ResponseField name="description" type="string">
              Description of the category
            </ResponseField>
          </Expandable>
        </ResponseField>
        
        <ResponseField name="created_at" type="string">
          Timestamp when the subcategory was created
        </ResponseField>
        
        <ResponseField name="updated_at" type="string">
          Timestamp when the subcategory was last updated
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>

```bash cURL
curl --location --request PUT 'https://api.yourapp.com/subcategories/1' \
--header 'Content-Type: application/json' \
--header 'Accept: application/json' \
--data-raw '{
  "name": "Premium Smartphones",
  "description": "High-end mobile phones and accessories"
}'
```

```javascript JavaScript
fetch('https://api.yourapp.com/subcategories/1', {
  method: 'PUT',
  headers: {
    'Content-Type': 'application/json',
    'Accept': 'application/json'
  },
  body: JSON.stringify({
    name: 'Premium Smartphones',
    description: 'High-end mobile phones and accessories'
  })
})
.then(response => response.json())
.then(data => console.log(data));
```

```python Python
import requests
import json

url = 'https://api.yourapp.com/subcategories/1'
headers = {
    'Content-Type': 'application/json',
    'Accept': 'application/json'
}
payload = {
    'name': 'Premium Smartphones',
    'description': 'High-end mobile phones and accessories'
}

response = requests.put(url, headers=headers, data=json.dumps(payload))
data = response.json()
print(data)
```
