---
title: 'Update Support Request'
description: 'Update an existing support request'
---

<Note>
  This endpoint requires authentication. Users can only update their own support requests.
</Note>

## Endpoint

<api-endpoint>
  <method>PUT</method>
  <url>/support-request/{id}</url>
</api-endpoint>

```http
PUT /support-request/{id}
```

## Authentication

This endpoint requires a valid JWT token. Include the token in the Authorization header:

```
Authorization: Bearer YOUR_JWT_TOKEN
```

## Path Parameters

<ParamField path="id" type="integer" required>
  The unique identifier of the support request to update
</ParamField>

## Request Body

<ParamField body="date" type="string" required>
  The date and time when support is needed. Must be a valid date format (e.g., `YYYY-MM-DD` or `YYYY-MM-DD HH:MM:SS`)
</ParamField>

<ParamField body="location" type="string" required>
  The location where support is needed. Must be at least 10 characters long
</ParamField>

<ParamField body="detail" type="string" required>
  A detailed description of the issue or support needed. Must be at least 10 characters long
</ParamField>

## Validation Rules

- **date**: Required, must be a valid date
- **location**: Required, must be a string, minimum 10 characters
- **detail**: Required, must be a string, minimum 10 characters

## Response

<ResponseField name="success" type="boolean" required>
  Indicates whether the request was successful
</ResponseField>

<ResponseField name="message" type="string" required>
  A human-readable message describing the result
</ResponseField>

<ResponseField name="data" type="object" required>
  The response data object
  
  <Expandable title="data properties">
    <ResponseField name="supportRequest" type="object" required>
      The updated support request object
      
      <Expandable title="SupportRequest properties">
        <ResponseField name="id" type="integer" required>
          Unique identifier for the support request
        </ResponseField>
        
        <ResponseField name="user_id" type="integer" required>
          ID of the user who created the support request
        </ResponseField>
        
        <ResponseField name="date" type="string" required>
          Date and time of the support request in ISO 8601 format
        </ResponseField>
        
        <ResponseField name="location" type="string" required>
          Location where the support is needed
        </ResponseField>
        
        <ResponseField name="detail" type="string" required>
          Detailed description of the support request
        </ResponseField>
        
        <ResponseField name="created_at" type="string" required>
          Timestamp when the support request was created
        </ResponseField>
        
        <ResponseField name="updated_at" type="string" required>
          Timestamp when the support request was last updated (will reflect the update time)
        </ResponseField>
        
        <ResponseField name="deleted_at" type="string | null">
          Timestamp when the support request was soft deleted (null if not deleted)
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

## Code Examples

<CodeGroup>

```bash curl
curl -X PUT https://api.example.com/support-request/1 \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -H "Accept: application/json" \
  -H "Accept-Language: en" \
  -d '{
    "date": "2026-03-16 14:00:00",
    "location": "Building A, Room 305 - Updated",
    "detail": "Network connectivity issues resolved. WiFi is now working properly."
  }'
```

```javascript JavaScript
const supportRequestId = 1;

const response = await fetch(`https://api.example.com/support-request/${supportRequestId}`, {
  method: 'PUT',
  headers: {
    'Authorization': 'Bearer YOUR_JWT_TOKEN',
    'Content-Type': 'application/json',
    'Accept': 'application/json',
    'Accept-Language': 'en'
  },
  body: JSON.stringify({
    date: '2026-03-16 14:00:00',
    location: 'Building A, Room 305 - Updated',
    detail: 'Network connectivity issues resolved. WiFi is now working properly.'
  })
});

const data = await response.json();
console.log(data.data.supportRequest);
```

```python Python
import requests

support_request_id = 1

response = requests.put(
    f'https://api.example.com/support-request/{support_request_id}',
    headers={
        'Authorization': 'Bearer YOUR_JWT_TOKEN',
        'Content-Type': 'application/json',
        'Accept': 'application/json',
        'Accept-Language': 'en'
    },
    json={
        'date': '2026-03-16 14:00:00',
        'location': 'Building A, Room 305 - Updated',
        'detail': 'Network connectivity issues resolved. WiFi is now working properly.'
    }
)

data = response.json()
print(data['data']['supportRequest'])
```

</CodeGroup>

## Error Responses

<ResponseField name="401 Unauthorized">
  Returned when the request is made without a valid JWT token or the token has expired
</ResponseField>

<ResponseField name="404 Not Found">
  Returned when:
  - The support request with the specified ID does not exist
  - The support request belongs to a different user (implicit ownership check)
</ResponseField>

<ResponseField name="422 Unprocessable Entity">
  Returned when validation fails. The response includes an `errors` object with field-specific error messages
</ResponseField>

## Behavior

- The `user_id` cannot be changed and remains associated with the original creator
- The `updated_at` timestamp is automatically updated when the record is modified
- All fields (`date`, `location`, `detail`) are required for the update

## Notes

- This is a full update endpoint (PUT), so all required fields must be provided
- Users can only update support requests they created
- The endpoint checks if the support request exists before attempting to update it
- Laravel's route model binding is used for automatic model retrieval
