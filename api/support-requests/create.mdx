---
title: 'Create Support Request'
description: 'Create a new support request'
---

<Note>
  This endpoint requires authentication. The support request will be automatically associated with the authenticated user.
</Note>

## Endpoint

<api-endpoint>
  <method>POST</method>
  <url>/support-request</url>
</api-endpoint>

```http
POST /support-request
```

## Authentication

This endpoint requires a valid JWT token. Include the token in the Authorization header:

```
Authorization: Bearer YOUR_JWT_TOKEN
```

## Request Body

<ParamField body="date" type="string" required>
  The date and time when support is needed. Must be a valid date format (e.g., `YYYY-MM-DD` or `YYYY-MM-DD HH:MM:SS`)
</ParamField>

<ParamField body="location" type="string" required>
  The location where support is needed. Must be at least 10 characters long
</ParamField>

<ParamField body="detail" type="string" required>
  A detailed description of the issue or support needed. Must be at least 10 characters long
</ParamField>

## Validation Rules

- **date**: Required, must be a valid date
- **location**: Required, must be a string, minimum 10 characters
- **detail**: Required, must be a string, minimum 10 characters

## Response

<ResponseField name="success" type="boolean" required>
  Indicates whether the request was successful
</ResponseField>

<ResponseField name="message" type="string" required>
  A human-readable message describing the result
</ResponseField>

<ResponseField name="data" type="object" required>
  The response data object
  
  <Expandable title="data properties">
    <ResponseField name="supportRequest" type="object" required>
      The newly created support request object
      
      <Expandable title="SupportRequest properties">
        <ResponseField name="id" type="integer" required>
          Unique identifier for the support request
        </ResponseField>
        
        <ResponseField name="user_id" type="integer" required>
          ID of the user who created the support request (automatically set to authenticated user)
        </ResponseField>
        
        <ResponseField name="date" type="string" required>
          Date and time of the support request in ISO 8601 format
        </ResponseField>
        
        <ResponseField name="location" type="string" required>
          Location where the support is needed
        </ResponseField>
        
        <ResponseField name="detail" type="string" required>
          Detailed description of the support request
        </ResponseField>
        
        <ResponseField name="created_at" type="string" required>
          Timestamp when the support request was created
        </ResponseField>
        
        <ResponseField name="updated_at" type="string" required>
          Timestamp when the support request was last updated
        </ResponseField>
        
        <ResponseField name="deleted_at" type="string | null">
          Timestamp when the support request was soft deleted (null for new requests)
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

## Code Examples

<CodeGroup>

```bash curl
curl -X POST https://api.example.com/support-request \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -H "Accept: application/json" \
  -H "Accept-Language: en" \
  -d '{
    "date": "2026-03-15 10:30:00",
    "location": "Building A, Room 305",
    "detail": "Network connectivity issues in the conference room. Unable to connect to WiFi."
  }'
```

```javascript JavaScript
const response = await fetch('https://api.example.com/support-request', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer YOUR_JWT_TOKEN',
    'Content-Type': 'application/json',
    'Accept': 'application/json',
    'Accept-Language': 'en'
  },
  body: JSON.stringify({
    date: '2026-03-15 10:30:00',
    location: 'Building A, Room 305',
    detail: 'Network connectivity issues in the conference room. Unable to connect to WiFi.'
  })
});

const data = await response.json();
console.log(data.data.supportRequest);
```

```python Python
import requests

response = requests.post(
    'https://api.example.com/support-request',
    headers={
        'Authorization': 'Bearer YOUR_JWT_TOKEN',
        'Content-Type': 'application/json',
        'Accept': 'application/json',
        'Accept-Language': 'en'
    },
    json={
        'date': '2026-03-15 10:30:00',
        'location': 'Building A, Room 305',
        'detail': 'Network connectivity issues in the conference room. Unable to connect to WiFi.'
    }
)

data = response.json()
print(data['data']['supportRequest'])
```

## Error Responses

<ResponseField name="401 Unauthorized">
  Returned when the request is made without a valid JWT token or the token has expired
</ResponseField>

<ResponseField name="422 Unprocessable Entity">
  Returned when validation fails. The response includes an `errors` object with field-specific error messages
</ResponseField>

## Behavior

- The `user_id` is automatically set to the authenticated user's ID
- When a support request is created, all administrators receive a notification
- The endpoint returns HTTP status code 201 (Created) on success
- All timestamps are automatically managed by Laravel

## Notes

- The `date` field accepts various date formats but will be stored and returned in ISO 8601 format
- Both `location` and `detail` must be at least 10 characters to ensure meaningful information
- Administrators are notified via Laravel's notification system when a new support request is created
