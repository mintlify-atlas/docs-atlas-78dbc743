---
title: 'List Support Requests'
description: 'Retrieve all support requests for the authenticated user'
---

<Note>
  This endpoint requires authentication. Users can only view their own support requests.
</Note>

## Endpoint

<api-endpoint>
  <method>GET</method>
  <url>/support-request</url>
</api-endpoint>

```http
GET /support-request
```

## Authentication

This endpoint requires a valid JWT token. Include the token in the Authorization header:

```
Authorization: Bearer YOUR_JWT_TOKEN
```

## Query Parameters

This endpoint does not accept any query parameters. It automatically filters results to show only support requests belonging to the authenticated user.

## Response

<ResponseField name="success" type="boolean" required>
  Indicates whether the request was successful
</ResponseField>

<ResponseField name="message" type="string" required>
  A human-readable message describing the result
</ResponseField>

<ResponseField name="data" type="object" required>
  The response data object
  
  <Expandable title="data properties">
    <ResponseField name="supportRequests" type="array" required>
      Array of support request objects ordered by ID in descending order (newest first)
      
      <Expandable title="SupportRequest object">
        <ResponseField name="id" type="integer" required>
          Unique identifier for the support request
        </ResponseField>
        
        <ResponseField name="user_id" type="integer" required>
          ID of the user who created the support request
        </ResponseField>
        
        <ResponseField name="date" type="string" required>
          Date and time of the support request in ISO 8601 format
        </ResponseField>
        
        <ResponseField name="location" type="string" required>
          Location where the support is needed
        </ResponseField>
        
        <ResponseField name="detail" type="string" required>
          Detailed description of the support request
        </ResponseField>
        
        <ResponseField name="created_at" type="string" required>
          Timestamp when the support request was created
        </ResponseField>
        
        <ResponseField name="updated_at" type="string" required>
          Timestamp when the support request was last updated
        </ResponseField>
        
        <ResponseField name="deleted_at" type="string | null">
          Timestamp when the support request was soft deleted (null if not deleted)
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

## Code Examples

<CodeGroup>

```bash curl
curl -X GET https://api.example.com/support-request \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -H "Accept: application/json" \
  -H "Accept-Language: en"
```

```javascript JavaScript
const response = await fetch('https://api.example.com/support-request', {
  method: 'GET',
  headers: {
    'Authorization': 'Bearer YOUR_JWT_TOKEN',
    'Accept': 'application/json',
    'Accept-Language': 'en'
  }
});

const data = await response.json();
console.log(data.data.supportRequests);
```

```python Python
import requests

response = requests.get(
    'https://api.example.com/support-request',
    headers={
        'Authorization': 'Bearer YOUR_JWT_TOKEN',
        'Accept': 'application/json',
        'Accept-Language': 'en'
    }
)

data = response.json()
print(data['data']['supportRequests'])
```

</CodeGroup>

## Error Responses

<ResponseField name="401 Unauthorized">
  Returned when the request is made without a valid JWT token or the token has expired
</ResponseField>

## Notes

- Support requests are automatically filtered by the authenticated user's ID
- Results are ordered by ID in descending order (newest first)
- The endpoint uses soft deletes, so deleted requests won't appear in the results
- When a support request is created, administrators are automatically notified
