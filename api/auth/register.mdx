# Register

Create a new user account with email, password, name, and phone number.

## Endpoint

```
POST /auth/register
```

## Request

<ParamField path="name" type="string" required>
  User's full name. Must be at least 2 characters.
</ParamField>

<ParamField path="phone" type="string" required>
  User's phone number. Must be at least 10 characters.
</ParamField>

<ParamField path="email" type="string" required>
  User's email address. Must be a valid email format and unique.
</ParamField>

<ParamField path="password" type="string" required>
  User's password. Must be at least 8 characters.
</ParamField>

<ParamField path="password_confirmation" type="string" required>
  Password confirmation. Must match the password field.
</ParamField>

## Response

<ResponseField name="success" type="boolean">
  Indicates whether the request was successful
</ResponseField>

<ResponseField name="message" type="string">
  Success message indicating the user was registered successfully
</ResponseField>

<ResponseField name="data" type="object">
  Response data containing the newly created user information
  
  <Expandable title="properties">
    <ResponseField name="user" type="object">
      User object containing profile information
      
      <Expandable title="properties">
        <ResponseField name="id" type="integer">
          User ID
        </ResponseField>
        
        <ResponseField name="role" type="string">
          User's role (default: "USER")
        </ResponseField>
        
        <ResponseField name="name" type="string">
          User's full name
        </ResponseField>
        
        <ResponseField name="email" type="string">
          User's email address
        </ResponseField>
        
        <ResponseField name="phone" type="string">
          User's phone number
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

## Example Request

<CodeGroup>

```bash curl
curl -X POST https://api.example.com/auth/register \
  -H "Content-Type: application/json" \
  -d '{
    "name": "John Doe",
    "phone": "+1234567890",
    "email": "john.doe@example.com",
    "password": "password123",
    "password_confirmation": "password123"
  }'
```

```javascript JavaScript
const response = await fetch('https://api.example.com/auth/register', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    name: 'John Doe',
    phone: '+1234567890',
    email: 'john.doe@example.com',
    password: 'password123',
    password_confirmation: 'password123'
  })
});

const data = await response.json();
```

```python Python
import requests

response = requests.post(
    'https://api.example.com/auth/register',
    json={
        'name': 'John Doe',
        'phone': '+1234567890',
        'email': 'john.doe@example.com',
        'password': 'password123',
        'password_confirmation': 'password123'
    }
)

data = response.json()
```

</CodeGroup>

## Example Response

```json
{
  "success": true,
  "message": "User registered successfully",
  "data": {
    "user": {
      "id": 2,
      "role": "USER",
      "name": "John Doe",
      "email": "john.doe@example.com",
      "phone": "+1234567890"
    }
  }
}
```
